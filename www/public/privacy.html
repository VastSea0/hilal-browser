Açık Kaynak & Şeffaf Gizlilik Taahhüdü

1. Giriş ve Açık Kaynak Şeffaflığı

Hilal Browser, VastSea (Egehan Kahraman) tarafından geliştirilen, açık kaynak kodlu ve gizlilik odaklı bir mobil web tarayıcısıdır. Kaynak kodlarımızın tamamı GitHub üzerinde herkese açıktır. Uygulamamızın hangi verileri nasıl işlediği, hangi ağ isteklerini gönderdiği herkes tarafından doğrudan incelenebilir.

2. Toplanan Veriler: Anonim Kullanım İstatistikleri

Masaüstü Hilal Browser hiçbir kullanım istatistiği göndermez. Android uygulaması, kaç kişinin hangi sürümü kullandığını görmek için günde en fazla bir kez şu bilgileri gönderir:

  • Uygulama ilk açıldığında rastgele üretilen bir kurulum kimliği
  • Uygulama sürümü ve derleme numarası
  • Android API seviyesi, işlemci mimarisi (ör. arm64-v8a) ve sistem dili
  • Seçili arama motoru, tema, uBlock Origin'in açık olup olmadığı ve yaklaşık sekme sayısı (1, 2-5, 6-10, 11+)

Bu istatistikler:

  • Ad, e-posta, telefon, cihaz modeli, reklam kimliği (GAID) veya donanım kimliği içermez.
  • Hiçbir kişiyle ilişkilendirilmez. IP adresiniz istatistik veritabanına yazılmaz; barındırma sağlayıcısı istekleri kısa süreli erişim kayıtlarında tutabilir.
  • Vercel üzerinde çalışan proje sunucusu aracılığıyla Google Cloud Firestore'da saklanır ve başka kimseyle paylaşılmaz.
  • Ayarlar > "Anonim kullanım istatistikleri" seçeneği kapatılarak tamamen durdurulabilir.

3. Asla Toplanmayan ve İletilmeyen Veriler

  • Tarama Geçmişi ve URL'ler: Ziyaret ettiğiniz hiçbir web sayfası sunucularımıza iletilmez.
  • Arama Sorguları: Adres çubuğuna yazdığınız aramalar ve Hilal Bangs kısayolları doğrudan arama motoruna iletilir; tarafımızca kaydedilmez.
  • Form ve Şifre Bilgileri: Yalnızca cihazınızda yerel tutulur.
  • Üçüncü Taraf Analitik SDK'ları: Uygulamada Firebase, Google Analytics, Facebook SDK veya benzeri takip kütüphaneleri yoktur.

4. Cihazınızda Yerel Olarak Saklanan Veriler

Yer imleriniz, geçmişiniz, Çalışma Alanları (Workspaces) ve çerezleriniz sadece kendi cihazınızın korumalı yerel belleğinde barındırılır. Ayarlar menüsündeki "Tarama Verilerini Temizle" butonuyla dilediğiniz an tek tıkla tamamen silebilirsiniz.

5. Para Kazanma Yöntemimiz: Yalnızca Sponsorlar

Hilal Browser ticari bir veri madenciliği veya reklam şirketi değildir:

  • Veri Satışı Yoktur: Verileriniz hiçbir şirkete satılmaz veya kiralanmaz.
  • Reklam Ağı Yoktur: Tarayıcı içinde reklam yer almaz.
  • Gelir Modeli: Projemizin tek gelir kaynağı gönüllü sponsorluklar ve bağışlardır (GitHub Sponsors ve açık kaynak destekçileri).

6. İzinler

  • INTERNET ve ACCESS_NETWORK_STATE: Web sitelerini açmak ve bağlantı durumunu görmek için.
  • CAMERA, RECORD_AUDIO, MODIFY_AUDIO_SETTINGS, ACCESS_COARSE_LOCATION ve ACCESS_FINE_LOCATION: Yalnızca bir web sitesi kamera, mikrofon veya konum istediğinde ve siz izin verdiğinizde kullanılır. Bu veriler o siteye gider, projeye gönderilmez.

Rehber ve dosya depolama izinleri istenmez.

Open Source & Transparent Privacy Commitment

1. Overview & Open Source Transparency

Hilal Browser is an open-source, privacy-first mobile web browser developed by VastSea (Egehan Kahraman). Our entire source code is publicly accessible on GitHub. Anyone can independently audit what data is processed and how our network calls behave.

2. Data Collected: Anonymous Usage Statistics

The Hilal desktop browser sends no usage statistics. To see how many people use which version, the Android app sends the following at most once a day:

  • A random installation ID created when the app first starts
  • The app version and build number
  • The Android API level, CPU architecture (for example arm64-v8a), and system language
  • The selected search engine, theme, whether uBlock Origin is on, and a rough tab count (1, 2-5, 6-10, 11+)

These statistics:

  • Contain no name, email, phone number, device model, advertising ID (GAID), or hardware identifier.
  • Are not linked to any person. Your IP address is not written to the statistics database; the hosting provider may keep requests in short-lived access logs.
  • Are stored in Google Cloud Firestore through the project's server on Vercel and are not shared with anyone else.
  • Can be turned off completely in Settings > "Anonymous usage statistics".

3. Data We NEVER Collect

  • No Browsing History or URLs: The web pages you browse never leave your device.
  • No Search Queries: Searches and Hilal Bangs go straight to the destination website; we do not intercept or log them.
  • No Form Inputs or Passwords: Stored strictly in on-device encrypted storage.
  • No Analytics SDKs: The app contains no Firebase, Google Analytics, Facebook SDK, or similar tracking library.

4. Local On-Device Storage

All bookmarks, workspaces, history, and cookies stay in your device's isolated application sandbox. You can purge everything instantly via Settings > "Clear Browsing Data". In Private Mode, session state is held strictly in temporary RAM and disappears the moment tabs are closed.

5. Monetization: Community Sponsors Only

  • No Data Brokering: We never sell, lease, or share data with third parties.
  • No In-App Advertising: Zero ads.
  • Funding Model: Supported solely through voluntary community sponsorships and donations (GitHub Sponsors).

6. Permissions

  • INTERNET and ACCESS_NETWORK_STATE: To load websites and check connectivity.
  • CAMERA, RECORD_AUDIO, MODIFY_AUDIO_SETTINGS, ACCESS_COARSE_LOCATION, and ACCESS_FINE_LOCATION: Used only when a website asks for the camera, microphone, or location and you allow it. That data goes to the website, not to the project.

Contacts and file storage permissions are not requested.
