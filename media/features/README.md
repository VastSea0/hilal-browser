# Feature media

Videos and images of Hilal Browser for the website, the docs, release notes
and social media. Everything here was recorded from a real build of Hilal on
macOS, in English, with a clean demo profile. Each step was checked while it
was recorded (the accent color really changes, the site color really comes
from the site, the boost really applies), so the captions describe what the
browser does.

- `videos/` are 1920x1080, 30 fps H.264 clips with captions, ready to post.
- `images/` are 2880x1800 stills with a framed window on a color background.
- `window/` holds the same stills as the bare window, for layouts that add
  their own frame.
