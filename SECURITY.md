# Security Policy

## Supported versions

Only the latest desktop release and the latest Android release receive fixes.
The desktop browser follows Firefox ESR, so most engine vulnerabilities are
fixed by moving to the next ESR point release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it privately through
[GitHub security advisories](https://github.com/VastSea0/hilal-browser/security/advisories/new).

Include the affected version and platform, the steps to reproduce, and what an
attacker could do with it. You will get an answer as soon as a maintainer can
look at it; Hilal is maintained by volunteers, so please allow some time.

If the problem is in Firefox or GeckoView itself and not in Hilal's changes,
report it to Mozilla instead:
<https://www.mozilla.org/security/report-bug/>.
